# Orion Advisor Solutions

> US wealth-tech provider (Omaha, NE) offering the credential-gated Orion Connect REST API for financial advisors and RIAs: portfolio accounting, trading and rebalancing (Eclipse), billing, reporting, planning, risk, compliance, and partner integrations. 5,460 operations under https://api.orionadvisor.com/api/v1; a test environment runs at https://testapi.orionadvisor.com/api/v1. Credentials are provisioned on request (SME-Integrations@orion.com). SOC 1/2, ISO 27001 and ISO 42001 attestations at trustcenter.orion.com.

## APIs

- [Orion API](https://developers.orionadvisor.com/): REST/JSON API for the Orion Portfolio Accounting System — Portfolio, Trading (Eclipse), Billing, Reporting, Orion Connect, Risk, Planning, Astro, Bulk Extracts, and Fuse notification webhooks
- [API Reference (Swagger UI)](https://api.orionadvisor.com/api/swagger/ui/index): live Swagger 2.0 contract for Orion Connect API v1

## Specs
